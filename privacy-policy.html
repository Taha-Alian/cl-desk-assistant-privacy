Privacy Policy — CL Desk Assistant

Last updated: 2026-05-05

CL Desk Assistant (“the extension”) does not collect, transmit, sell, or share any user data with any party.

What the extension stores

All user-configurable settings are stored locally in your browser via the chrome.storage API. These include:

  • Refresh interval
  • CSS selector for the refresh target
  • Allowed URL prefixes
  • Refresh type (XHR vs. full page reload)
  • Startup behavior (resume last state / auto-start / paused)
  • The “Only when Zendesk tab is active” toggle
  • Whether the engine is currently running (Start / Stop state)

No personal information, ticket content, reply drafts, customer data, or browsing history is read, stored, or transmitted by the extension.

What the extension does NOT do

  • It does not make any network requests to remote servers.
  • It does not include analytics, telemetry, or tracking of any kind.
  • It does not load third-party scripts.
  • It does not read or modify ticket text, comments, or any other Zendesk content beyond invoking the user-configured refresh action (a click on the user-selected element, or a page reload).
  • It does not run on any site other than https://*.zendesk.com/*.

Permissions

  • storage — to save your refresh settings between browser sessions.
  • Host access for https://*.zendesk.com/* — to inject the refresh action on Zendesk pages and to read the page URL for user-defined per-view targeting.
